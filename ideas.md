## Idea A — "Editorial Precision"

**Design Movement:** Swiss International Typographic Style meets modern tech editorial

**Core Principles:**
1. Radical whitespace — sections breathe, nothing competes
2. Typography as visual hierarchy — size contrast does the heavy lifting
3. Strict left-aligned grid — predictable, scannable, zero confusion
4. Color used as punctuation, not decoration

**Color Philosophy:**
- Background: Pure white #FFFFFF (dominant)
- Primary text: Near-black #0D0D0D
- Navy accent: #102E4F for section headers and nav
- Orange spark: #FF653B only for CTAs and key numbers
- Light gray: #F5F5F5 for alternating section backgrounds

**Layout Paradigm:**
Asymmetric editorial grid — headline bleeds left, content sits right. Services as horizontal numbered list. Works as full-bleed image grid. No centering except hero tagline.

**Signature Elements:**
1. Large oversized section numbers (01, 02, 03) in light gray as background texture
2. Thin horizontal rules separating sections with label tags
3. Orange underline accent on key words in headlines

**Interaction Philosophy:**
Hover reveals — cards lift subtly, underlines animate from left to right, CTAs fill with color on hover.

**Animation:**
- Fade-up on scroll (translateY 20px → 0, opacity 0 → 1, 0.4s ease)
- Nav items: underline slides in from left on hover
- CTA buttons: background fills from left on hover (clip-path animation)
- Numbers count up on viewport entry

**Typography System:**
- Display: DM Sans 700/800 — large, bold, confident
- Body: DM Sans 400 — clean, readable
- Thai: Noto Sans Thai 400/600
- Scale: 72px hero → 48px section → 32px card → 16px body

## Idea B — "Structured Clarity" (SELECTED)

**Design Movement:** Contemporary B2B SaaS meets Thai corporate modernism

**Core Principles:**
1. Zero cognitive load — one message per section, crystal clear hierarchy
2. Dark navy as anchor — grounds the page without heaviness
3. Generous padding — content never feels cramped
4. Functional beauty — every element earns its place

**Color Philosophy:**
- Background: #FAFAFA (off-white, softer than pure white)
- Section accent: #102E4F (navy) for hero and footer — bookends the page
- Highlight: #FF653B (orange) for CTAs, stats, and key moments only
- Neutral: #E8E8E8 for dividers and subtle backgrounds
- Text: #1A1A1A primary, #6B7280 secondary

**Layout Paradigm:**
Full-width sections with contained content (max-w-6xl). Hero: left-heavy with large type + right visual. Services: 2-column with icon + text. Works: masonry-style card grid. Solutions: horizontal 3-column cards.

**Signature Elements:**
1. Pill-shaped section labels (e.g., "WHAT WE DO") in orange before each heading
2. Stats row with large orange numbers on navy background
3. Testimonial cards with subtle left border in orange

**Interaction Philosophy:**
Smooth, purposeful — scroll-triggered reveals, hover states that confirm interactivity without being flashy.

**Animation:**
- Section entrance: staggered fade-up (0.1s delay between items)
- Service cards: border-left grows on hover
- CTA buttons: scale(1.02) + shadow on hover
- Stats: count-up animation when in viewport

**Typography System:**
- EN Display: DM Sans 800 — authoritative, modern
- EN Body: DM Sans 400/500
- TH: Noto Sans Thai 400/600
- Hero: 64px, Section titles: 44px, Cards: 24px, Body: 16px/1.7 line-height

## Idea C — "Kinetic Minimalism"

**Design Movement:** Motion-first minimalism — Stripe/Linear aesthetic adapted for Thai market

**Core Principles:**
1. Motion communicates — subtle animations tell the story
2. Monochromatic base with single accent — visual discipline
3. Card-free layout — content flows in open space
4. Bold typographic moments — one big statement per section

**Color Philosophy:**
- Background: #FFFFFF
- Gradient accents: #102E4F → #1a4a7a subtle gradient on hero
- Orange: #FF653B as the single accent color (sparingly)
- Gray scale: #F8F8F8, #E5E5E5, #9CA3AF, #374151

**Layout Paradigm:**
Single-column narrative flow with full-viewport sections. Services as horizontal scrollable strip. Works as overlapping card stack. Testimonials as infinite marquee.

**Signature Elements:**
1. Gradient text on hero headline (navy to blue)
2. Floating geometric shapes (circles, lines) as background decoration
3. Horizontal scrolling services ticker

**Interaction Philosophy:**
Parallax scrolling on hero, magnetic hover on buttons, cursor follower effect.

**Animation:**
- Hero text: word-by-word reveal animation
- Services ticker: continuous horizontal scroll
- Parallax: hero image moves at 0.5x scroll speed
- Cursor: custom cursor with magnetic pull on interactive elements

**Typography System:**
- Display: Clash Display or DM Sans 900 — ultra bold
- Body: DM Sans 400
- TH: Noto Sans Thai
- Hero: 80px, Sections: 52px
